# Sunwise Android wrapper

This small Android app opens the live Sunwise PWA at `https://benjihamo.github.io/Solar-Predict/`. Its screen, forecast data and PWA updates come from that site, so it requires an internet connection. Preferences and calibration remain local to this Android WebView installation; they do not sync automatically with the standalone browser/PWA.

The wrapper supports Android 7.0 (API 24) and newer, and targets API 36 for current Play submissions. It asks for approximate Android location permission only after the user taps the location control in Sunwise and confirms the disclosure. If permission is declined, coordinates can still be entered manually.

## Build

The `Build Android APK` GitHub Actions workflow builds a debug APK on pushes to `main` that change this directory, or when manually started. Download `sunwise-android-debug` from the completed workflow run's Artifacts section, unzip it, and install `app-debug.apk` on the phone. Android may ask to allow installs from the browser used to download the file.

The debug APK is signed with the standard debug key generated by the build. It is for testing and direct installation, not a Play Store release. New Play Store submissions need a signed Android App Bundle (AAB), not this debug APK.

## Build a Play upload bundle

1. Generate an upload key on a trusted computer and keep the `.jks` file and passwords backed up securely. Never commit them to this repository.
2. Add these encrypted GitHub Actions repository secrets: `PLAY_UPLOAD_KEYSTORE_BASE64`, `PLAY_UPLOAD_STORE_PASSWORD`, `PLAY_UPLOAD_KEY_ALIAS`, and `PLAY_UPLOAD_KEY_PASSWORD`.
3. Open the **Build Android APK** workflow, choose **Run workflow**, and set **Build a signed Play Store App Bundle** to true.
4. Download the `sunwise-play-store-aab` artifact. Upload `app-release.aab` in Play Console's internal testing track first.

The workflow runner uses the key only for the build and deletes its temporary workspace afterward. For production release, use Play App Signing and keep the upload key private. A debug APK and a Play-signed install may not update over one another; uninstall the debug build first if Android reports a signature mismatch.
